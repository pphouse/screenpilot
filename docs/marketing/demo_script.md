# ScreenPilot Demo Video Script

## Video Specs
- Duration: 90-120 seconds
- Format: Screen recording with voiceover
- Resolution: 1920x1080
- Music: Upbeat tech background (low volume)

---

## Script

### Scene 1: Problem (0:00 - 0:15)
**Visual:** Montage of RPA error screens, broken selectors, error logs
**Voiceover:**
> "Your RPA scripts break every time the UI updates. You spend more time fixing automations than they save. Sound familiar?"

### Scene 2: Introduction (0:15 - 0:25)
**Visual:** ScreenPilot logo animation, then terminal window
**Voiceover:**
> "Meet ScreenPilot. AI desktop automation that sees the screen like a human."

### Scene 3: Natural Language Demo (0:25 - 0:50)
**Visual:** Terminal showing the command being typed and executed
```
$ screenpilot run "Open Chrome, navigate to github.com, and search for 'screenpilot'"
```
**Voiceover:**
> "Just describe what you want in plain English. ScreenPilot uses AI vision to understand the screen, plan the steps, and execute them - all automatically."

**Visual:** Show step-by-step execution log with "OK" markers
> "Step 1: Click Chrome... Step 2: Click address bar... Step 3: Type URL... Every action is planned by AI and verified visually."

### Scene 4: Self-Healing (0:50 - 1:05)
**Visual:** Split screen - left shows UI before update, right shows UI after update
**Voiceover:**
> "And when the UI changes? ScreenPilot adapts. No selectors to fix. No scripts to update. The AI finds the element wherever it moved."

### Scene 5: Features Montage (1:05 - 1:30)
**Visual:** Quick cuts showing:
- Web dashboard with live execution
- Schedule configuration
- Slack notification arriving
- HTML execution report
- Python SDK code

**Voiceover:**
> "Schedule tasks to run unattended. Get notified on Slack when they complete. Generate execution reports for stakeholders. Integrate via Python SDK or REST API. And extend with plugins."

### Scene 6: CTA (1:30 - 1:45)
**Visual:** GitHub page with star button highlighted
**Voiceover:**
> "ScreenPilot is open source and free forever. Star us on GitHub and start automating in minutes."

**Text on screen:**
```
github.com/pphouse/screenpilot
pip install screenpilot
```

---

## Key Messages to Convey

1. **Problem:** Traditional RPA is brittle and expensive
2. **Solution:** AI vision replaces CSS selectors
3. **Ease:** Natural language descriptions, not scripts
4. **Resilience:** Self-healing, adapts to UI changes
5. **Enterprise-ready:** Scheduling, notifications, reports
6. **Free:** Open source, Apache 2.0

## Recording Tools
- OBS Studio for screen recording
- Any terminal with dark theme
- Chrome browser for web demo portions
- ScreenPilot web dashboard running at localhost:8420
