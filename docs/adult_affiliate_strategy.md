# アダルトアフィリエイト ブログ戦略

## 概要
lisaアカウントとは**完全に分離した別垢+ブログ**で運営。顔出し不要、属人性ゼロで、FANZA/DMMアフィリエイトを中心に月5〜30万円を目指す。

---

## 1. プラットフォーム選定

### メイン収益源: FANZA (DMM) アフィリエイト
- **報酬率**: 動画 10%、電子書籍(同人) 15〜20%+
- **Cookie有効期間**: 90日 (業界最長クラス)
- **リピート購入率が高い** → 一度リンクを踏んだユーザーが繰り返し購入
- **まとめ買い発生** → 1クリックから複数商品の報酬が入る

### サブ収益源
- **Amazonアソシエイト** (一般書籍・グッズ系)
- **楽天アフィリエイト** (補助的)
- **A8.net / afb** (マッチングアプリ案件 → 高単価)
- **Google AdSense** (PV型、アダルトは不可 → 一般記事のみ)

## 2. ブログ設計

### 技術スタック
- **WordPress** (エックスサーバー or ConoHa WING)
- 独自ドメイン (.com / .net)
- SSL必須
- アダルト可のレンタルサーバー: **mixhost** or **カラフルボックス** (エックスサーバーはアダルト不可)

### サイト構成
```
トップページ
├── カテゴリ1: 新作レビュー (毎週更新)
├── カテゴリ2: ジャンル別おすすめ (まとめ記事)
├── カテゴリ3: 女優別まとめ (指名検索狙い)
├── カテゴリ4: セール・キャンペーン情報
└── カテゴリ5: 読み物コラム (SEO集客用)
```

### 記事テンプレート

#### A. 新作レビュー記事 (量産メイン)
```
タイトル: 【レビュー】{作品名} {女優名} — {一言感想}
構成:
  - 作品情報 (サムネ、女優、メーカー、発売日)
  - あらすじ
  - 見どころ3つ
  - 評価 (★5段階)
  - FANZAリンク (アフィリンク)
文字数: 1000〜1500字
```

#### B. まとめ記事 (CVR高い)
```
タイトル: 【2026年最新】{ジャンル}おすすめ作品10選
構成:
  - ランキング形式で10作品紹介
  - 各作品にアフィリンク
  - 比較表
文字数: 3000〜5000字
```

#### C. 女優特集 (指名検索)
```
タイトル: {女優名}のおすすめ作品まとめ【全○本から厳選】
構成:
  - プロフィール
  - 代表作5〜10本
  - ジャンル別おすすめ
文字数: 2000〜3000字
```

#### D. セール記事 (即効性)
```
タイトル: 【○月最新】FANZAセール・クーポン情報まとめ
構成:
  - 現在開催中のセール一覧
  - おすすめピックアップ
  - クーポンコード
文字数: 1000〜2000字 (随時更新)
```

## 3. SEO戦略

### キーワード設計
```
【収益キーワード (CVR高)】
- "{作品名} レビュー"
- "{女優名} おすすめ"
- "{ジャンル} おすすめ 動画"
- "FANZA セール 今月"
- "{女優名} 無料動画" → FANZAのサンプル動画ページへ誘導

【集客キーワード (PV型)】
- "{女優名} 引退"
- "{女優名} プロフィール"
- "FANZA 使い方"
- "FANZA 支払い方法"
```

### SEOのポイント
- **ロングテール狙い**: 「{女優名} {ジャンル} おすすめ」のような3語以上
- **新作は即記事化**: 発売日当日に公開 → 競合が少ない
- **内部リンク充実**: 女優記事 ↔ レビュー記事 ↔ まとめ記事
- **更新頻度**: 週3〜5記事 (最初の3ヶ月は毎日)

## 4. SNS集客 (ブログへの導線)

### X (Twitter) 別アカウント
- **完全匿名運用** (lisaアカウントとは一切紐付けない)
- プロフィール: 「アダルト作品レビューブログ運営中。新作情報毎日更新。」
- **投稿内容**: 新作情報、セール告知、レビュー記事リンク

```
  「今週のFANZA売上ランキングTOP5
   1位: {作品名}
   ...
   詳細レビューはブログで → {リンク}」
```

## 7. リスク管理

### アカウントBAN対策
- ブログとSNS垢は**完全に分離** (異なるメールアドレス、IP)
- X垢は**センシティブ設定ON**
- 過激な表現は避ける (規約ギリギリを攻めない)

### 法的リスク
- **著作権**: FANZAアフィリエイター向け素材のみ使用
- **薬機法**: サプリ・精力剤系は表現に注意
- **18禁表記**: サイトトップに年齢確認ゲート設置

### SEOリスク
- Googleアップデートで順位変動 → **複数流入経路**を確保 (X, ブックマーク, 直接)
- 違法サイトとの差別化 → **正規配信への誘導**を明確に
